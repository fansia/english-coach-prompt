# ChatGPT 英文口說家教

> **線上版 → https://eric-yen.com/english-coach-prompt/**（English → `/english-coach-prompt/en/`）

不用花錢補習，也有一個會配合你程度的口說老師。

把這段 prompt 貼給 ChatGPT，請它設定成每天提醒的 schedule。上課過程中想調整，調整完再請它存下來，等於是一個每天可以自己客製的英文家教：

- 聽不懂的次數增加會自動放慢語速，表現好又會加快
- 講得不好時，幫你改得更 native，並請你重複矯正過的句子
- 句子太長會拆成一個片語一個片語帶你念
- 每次結束前，帶你用口說複習今天的 2–5 個關鍵表達

Prompt 全文在 `index.html` 裡（`PROMPT`），頁面上可以一鍵複製。用手機的 ChatGPT app 開語音上課最順。
